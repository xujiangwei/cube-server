以对话方式进行绘画解读

该文档用于说明如何开发基于对话的方式进行心理学绘画测试。

以下步骤是一个标准的数据处理流程：

  1. 上传绘画文件；
  2. 调用 /aigc/psychology/converse 接口，使用该接口提交提示词和上传文件的文件码；
  3. 如果提示词信息不足，AiXinLi模型会引导补全信息，这个过程是一个正常的对话交互过程，使用 /aigc/psychology/converse 接口；
  4. 进入推理流程后，UI应该进入等待状态，UI程序轮询 /aigc/psychology/report/part 接口获取报告状态和数据。
  5. 使用返回的报告内容数据填充到UI程序。

第一步 - 上传绘画文件

上传文件调用 上传文件数据 接口。

上传文件后使用 查找已上传的文件 接口查询文件状态，确保文件已正确上传到服务器。

第二步 - 提交提示词和文件码

使用 互动对话 同时提交用户的提示词和文件的文件码。

请求数据如下所示：

{
    "channelCode": "mnxRSaLdPuHEVaKA",
    "context": [
        "fileCode": "yEryPsWMYphCHatmTRmoPMvlSKqyfJCFkchtgjgFYVfKQaAzmnbVHHboRYwquJJY"
    ],
    "query": "画里能看出什么心理状态"
}

提示：频道码channelCode是管理对话和查询对话记录的唯一标识，因此UI程序应当有统一的管理机制。另推荐频道码如示例所示采用16位随机字符串。

第三步 - 根据模型返回数据判断如何进行交互

经过第二步调用，AiXinLi模型会根据提示词推理是否开始进行绘画心理学推理任务。

进行绘画心理学推理时，模型需要知道被测人的年龄和性别等信息，因此在返回数据的answer字段会提示用户告知这些必要信息。

在程序中，应当通过判断返回数据是否有context字段，同时context.inferring的值是否为true，依此判断模型是否开始进行子任务推理。如果没有进入子任务推理，则按照正常的对话交互流程进行相关UI操作。

第四步 - 获取子任务推理数据

如果context.inferring为true值，表示模型开始进行子任务推理，此时UI应当进入等待状态，这时如果UI程序继续提交对话会被服务器拒收。

因此，当进入子任务推理后，数据context.resources.payload.attachments.id字段为绘画报告的序列号，调用 获取报告指定部分信息 接口查询报告生成状态和生成内容。

请求示例：

http://211.157.179.37:7010/aigc/psychology/report/part/UQYrEcbPaZhHSBvJippdpPrwvIfvuPlG?sn=3325739656&content=true

参数sn即是context.resources.payload.attachments.id字段数据。

接口返回的数据中，state表示推理状态。当状态为0值时，字段content即为推理后的内容，该内容格式为Markdown格式。

第五步 - 显示报告数据

通过 获取报告指定部分信息 接口获取到content数据，进行Markdown渲染显示。

至此对话方式推理报告就完成了。
